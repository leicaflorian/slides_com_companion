## Development

- **What it is**: a Chrome/Edge MV3 extension for slides.com. The background enables the action and shows the coloured icon (no badge) on tabs with a presentation; the content script waits for the presentation, sets up a `<script id="slc-injected-script">` that bridges settings through custom events, and asks the background to run the injectable script in the MAIN world; the injectable registers Reveal's notes plugin (speaker view) and mounts a Vue toolbar that prints by reloading the presentation with `?print-pdf` (Reveal's own print view; Slides.com blocks `view: 'print'` for free accounts and no longer allows a second `Reveal.initialize`). The popup edits `settings` in `chrome.storage.sync`.
- **Stack**: WXT + `@wxt-dev/module-vue`, Vue 3 + TypeScript (strict, `vue-tsc`), Bootstrap 5 in the popup, Vitest + `wxt/testing` (`fakeBrowser`) + happy-dom for unit tests, Playwright for e2e, ESLint + Prettier. Layout and commands are in `README.md`. TypeScript stays on 5.x until `vue-tsc` supports 7.
- **WXT quirks**: WXT imports entrypoints at build time to read their options, so an entrypoint must not import a `.vue` file with a `<style lang="scss">` block (the build fails with "Cannot read properties of undefined (reading 'scss')"); the toolbar styles live in `src/entrypoints/content/style.scss`. The action title comes from the popup's `<title>`. The injected script is `/injected.js` and must stay in `web_accessible_resources`.
- **Node 22**: run `source ~/.nvm/nvm.sh && nvm use` before any `npm`/`npx` command. `npm install` also runs `wxt prepare`, which `typecheck` needs. The e2e tests need `npx playwright install chromium`.
- **The e2e fixtures**: `tests/fixtures/presentation/` (the presentation page) and `tests/fixtures/fullscreen/` (its `/fullscreen` view) are a public presentation saved with `npm run snapshot -- <url> [name]` (fresh profile, no login, CSRF token scrubbed, no images). The tests serve them at their real URLs and block the network. Printing always goes through the fullscreen view (the presentation page prints the rest of the page too); Slides.com's fullscreen view drops `?print-pdf` on Reveal's `pdf-ready` event, so `src/entrypoints/print-view.content.ts` (MAIN world, `document_start`) stops that event when the URL has `print-pdf`. `EXTENSION_DIR=<dir> npx playwright test` runs the suite against another build.
- **Images that show the toolbar**: when the toolbar's look changes, run `npm run toolbar-image` (the popup image), update `.github/assets/og-image.html` and run `npm run og-image`, then `npm run store-assets` for the Chrome Web Store images (frames in `.github/assets/store/`, captures taken live on a public presentation, output in `.output/store-assets/`).
- **Versions**: the version comes from `package.json`.
- **Merging into `dev`**: the owner decides; for a phase branch prefer a squash merge with one English commit message.
